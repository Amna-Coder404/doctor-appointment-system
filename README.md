# CareUp 💙

### Your Healthcare, Made Easier.

CareUp is a modern patient-focused healthcare mobile application built with **React Native and Expo**. It allows patients to explore doctors, track appointment status, cancel appointments, manage profiles, and receive notifications.

## 🛠️ Tech Stack

<p align="center">

**React Native · Expo · Supabase · SQLite · JavaScript**

</p>


<div align="center">

| **Technology** | **Purpose** |
|:---:|:---:|
| React Native | Mobile app development |
| Expo | App development and builds |
| Supabase | Authentication and backend |
| SQLite | Local database and offline support |
| Expo Router | Navigation |
| React Native Reanimated | Animations |

</div>


## ✨ Features

- Explore doctors and view their profiles.
- Track appointment details and status.
- Cancel appointments.
- Manage patient profiles.
- Receive appointment notifications.
- Offline support with SQLite.
- Animated bottom-tab navigation.

## 🚀 Getting Started

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd doctor-appointment-system
npm install
```

Create a `.env` file:

```env
EXPO_PUBLIC_SUPABASE_URL=your_supabase_project_url
EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

Start the app:

```bash
npx expo start
```
